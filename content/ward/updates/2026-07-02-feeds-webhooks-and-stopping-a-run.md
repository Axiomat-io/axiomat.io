## Point an assistant at any feed

Ask an assistant to follow a blog, a news source, a release page, a regulator's notices — anything that publishes a feed. You don't need to find the feed URL yourself; describe the site and Ward goes looking for one.

Feeds turn out to be the cheapest way to make a monitor genuinely useful. A competitor watcher that reads their changelog directly is a different thing from one guessing at a homepage.

## Something else can start a run

An assistant can now be triggered from outside Ward. If another tool you use can send a web request when something happens, it can wake an assistant up — a form submission, a deploy, an alert.

Everything you'd expect still applies: the assistant runs under the same permissions you gave it, and anything that changes something still waits for your approval.

## Stop a run you didn't mean to start

If a chat run is going somewhere you didn't intend, you can stop it. You can also stop it and edit what you asked, rather than starting over — useful when the request was nearly right.
