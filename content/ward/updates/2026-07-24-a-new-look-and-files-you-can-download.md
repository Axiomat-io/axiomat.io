The biggest visible change since Ward started.

## Ward looks like itself now

Ward was built fast and looked it — everything in monospace, the palette of a terminal. It now has a considered design: a typeface meant for reading, monospace kept for the things that genuinely are data, and one calm accent instead of whatever each screen felt like.

Nothing moved. Everything reads more easily, and the eleven themes all inherit it, so switching one still changes the whole app.

## Assistants can hand you a file

An assistant can now produce a real file you download — a CSV of what it's tracking, a written-up brief, a log of findings. It appears on the assistant's page, and it's a file, not a wall of text in a chat you have to copy out of.

<!-- SCREENSHOT: an assistant page showing a produced file with its download control -->

## The assistant page, reorganised

An assistant's page had grown into one long column. It's now grouped into cards, with the things you check daily open and the set-and-forget configuration tucked away until you want it.

## Somewhere to start

A new chat used to be a greeting and an empty box, which is a hard place to begin. It now offers a few starting points, and they change with your workspace — a first assistant if you have none, something relevant if you do. They disappear the moment you type.
