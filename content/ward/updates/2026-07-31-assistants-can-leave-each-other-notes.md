If you run more than one assistant, they've had no way to talk to each other — a news monitor that spots something a market tracker would care about had no way to say so.

An assistant can now send a short note to another assistant you own. The note shows up automatically the next time that assistant runs, and only once — no digging through history to find it.

This is a note, not a request. Sending one doesn't start the other assistant early or wait for a reply — it just sits there until that assistant's next scheduled or manual run, same as it would have gone anyway.
